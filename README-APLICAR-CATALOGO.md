# Aplicar catálogo dinâmico

Este ZIP é incremental e foi preparado sobre o estado atual do repositório `oluisvi/Ferreira-Im-veis`.

1. Extraia os arquivos sobre o projeto atual.
2. Confirme as substituições.
3. Rode `npm test` e `npm run build`.
4. Importe `docs/google-sheets/ferreira-imoveis-template.csv` em uma Google Sheet.
5. Configure as variáveis do Vercel indicadas em `.env.example`.
6. Faça deploy.

A cena de entrada, motion das sections, CTA flutuante e hotfix do telhado da contact permanecem intactos.
