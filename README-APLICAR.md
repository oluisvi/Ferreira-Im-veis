# Ferreira Imóveis — sincronização da entrada temática

Este ZIP contém somente os arquivos alterados para a melhoria da cena de entrada.

## Como aplicar

1. Extraia o conteúdo deste ZIP sobre a raiz do repositório `Ferreira-Im-veis`.
2. Confirme a substituição dos arquivos existentes.
3. Não apague os demais arquivos do repositório.
4. Rode `npm test` e `npm run build` no seu ambiente com as dependências instaladas.
5. Faça commit/push normalmente; a Vercel deve gerar o novo deploy.

## Arquivos alterados

- `index.html`
- `src/components/Hero.tsx`
- `src/components/IntroPortal.tsx`
- `src/components/IntroPortal.test.tsx`
- `src/styles/motion.css`

Nenhuma dependência nova foi adicionada.
